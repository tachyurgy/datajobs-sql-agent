# Releases

## 2026-09-29 — First release: askdata.levelbrook.com
- **What deployed:** https://askdata.levelbrook.com (Cloudflare Pages project `askdata`): the ask page (DuckDB-WASM over the 2026-09-29 Observatory snapshot, 11 tables), `/accuracy` (eval results page), and the `/api/ask` Pages Function (prompt builder + Gemini proxy with KV rate limits).
- **Changed:**
  - Live model Gemini 2.5 Flash (thinking off) at ablation d, measured at 78% overall (95% CI 67-88%) on the 60-question gold set; fallback Gemini 2.5 Flash-Lite at ablation e (73%, 62-83%) on quota errors; answer sentences from Flash-Lite.
  - Eval of three free-tier models x five ablations committed under `results/`, with the reply cache for offline re-scoring.
  - duckdb-wasm pinned to 1.33.1-dev57.0 (DuckDB 1.5.4) and the Python engine pinned to 1.5.4 after a live question exposed an engine-version gap; ICU loaded before the session is locked.
  - Six cached example answers, each checked against an independent query; candidates whose SQL or summary was wrong were dropped or re-scoped (for example "open remote-US" added), never edited.
- **How:** `make deploy` (exports assets, renders the report, runs `wrangler pages deploy public` from `web/` so `functions/` ships; "Compiled Worker successfully" confirmed). Secrets: GEMINI_API_KEY, LBTRACK_KEY, LBTRACK_URL (Pages secrets); KV namespace `askdata-ratelimit` bound as RL. Custom domain via the Pages domains API + proxied CNAME `askdata -> askdata-2f6.pages.dev`.
- **Verified:** `/`, `/accuracy`, `/data/*.parquet`, `/data/examples.json`, `/api/ask` return 200 on the custom domain. In headless Chromium against the live site, 7 questions asked: 5 correct against independently written queries (median ML engineer pay 221,875; 14 PhD-floor data scientist listings; 153 PyTorch listings; 96 Kafka listings; an applicant-gender question refused), 2 wrong (a data-engineer count that queried `mart_daily_market` with `seniority IS NULL` and came back empty three times; a top-3 companies question answered from `dim_company`'s per-posting counter instead of canonical listings). Browser session reports TimeZone UTC and ICU loaded; no horizontal overflow at 390px; cross-origin POST to `/api/ask` returns 403; the rate-limited path (429) shows the notice and cached examples still run. 84 pytest tests pass, including byte-identical prompt parity between the Python eval and the JS runtime.
