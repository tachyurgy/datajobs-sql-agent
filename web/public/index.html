    How it works

    1. Your question is matched against a data dictionary (every column's description and sample values) with BM25; the best-matching column docs and the three most similar worked examples go into the prompt with the full schema.
    2. Gemini writes one DuckDB query, or refuses when the data cannot answer the question.
    3. A read-only guard checks it (single SELECT/WITH, known tables only, no file or network access), then your browser runs it with a 10-second timeout.
    4. If it errors or returns nothing, the error goes back to the model for up to two corrections.
    5. A second short call turns the result into a sentence. The same prompt code is used by the offline eval.
    Data: Data Jobs Observatory snapshot of 2026-09-29 (public job-board APIs). Model: Gemini, free tier. Answers can be wrong; the SQL is shown so you can check. Built by Levelbrook.
